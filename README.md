# 🧬 AI Cancer Prediction Platform

A Machine Learning web application that predicts the possibility of **Breast Cancer** and **Lung Cancer** using medical input data.

The application is built with **Python, Flask, and Scikit-learn** and uses **Random Forest Classifier** models to generate predictions.

---

## 📌 Project Description

The **AI Cancer Prediction Platform** is an educational healthcare application that demonstrates the integration of Machine Learning with Web Development.

Users can enter the required medical parameters and select the type of cancer they want to check. The trained Machine Learning model processes the information and displays the prediction result.

The application also provides general information about cancer, symptoms, treatments, hospitals, and patient resources.

> ⚠️ **Disclaimer:** This application is developed for educational purposes only. The predictions should not be considered a medical diagnosis or a replacement for professional medical advice.

## 🧠 Machine Learning Models

The application uses two separate Machine Learning models.

### 🩺 Breast Cancer Model

**Dataset:** Breast Cancer Wisconsin Dataset

**Algorithm:** Random Forest Classifier

**Reported Accuracy:** 96.49%

### 🫁 Lung Cancer Model

**Dataset:** Lung Cancer Dataset

**Algorithm:** Random Forest Classifier

**Reported Accuracy:** 91.66%

### Model Summary

| Cancer Type   | Algorithm                | Accuracy |
| ------------- | ------------------------ | -------: |
| Breast Cancer | Random Forest Classifier |   96.49% |
| Lung Cancer   | Random Forest Classifier |   91.66% |

> The reported accuracy can vary depending on the dataset, preprocessing method, train/test split, and model configuration.
